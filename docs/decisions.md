# Architecture Decision Records (ADR)

กติกา: ตัดสินใจเชิงสถาปัตยกรรมใหม่ทุกครั้ง → เพิ่ม ADR ที่นี่ก่อนเขียนโค้ด
รูปแบบ: บริบท → ตัดสินใจ → เหตุผล → เงื่อนไขที่จะทบทวน

## ADR-001: สถาปัตยกรรมเดียว สองโหมด (ไร้กล่อง + กล่อง Edge)
- **ตัดสินใจ:** ระบบกลางรับ NormalizedEvent โดยไม่สนแหล่งที่มา / โหมดไร้กล่องเป็นค่าเริ่มต้น / กล่อง Frigate เป็น upsell
- **เหตุผล:** ไร้กล่อง = friction ต่ำสุด ปิดดีลเร็ว ตรงวิสัยทัศน์ Plug & Play; กล่องแก้ปัญหากล้องเก่า/เน็ตห่วย/ฟีเจอร์พิเศษ และเป็นรายได้เพิ่ม
- **ทบทวนเมื่อ:** ไซต์ส่วนใหญ่กล้องเก่าเกินจนโหมดไร้กล้องขายไม่ได้จริง

## ADR-002: TypeScript ทั้งระบบ ไม่มี Python ใน MVP
- **เหตุผล:** งาน vision หนักอยู่ที่กล้อง/กล่อง ไม่ใช่คลาวด์; โค้ดเบสภาษาเดียวดูแลง่ายสำหรับทีมเล็ก; ผู้พัฒนาใช้ stack นี้คล่อง + AI coding tools ทำงานกับมันได้ดีที่สุด
- **ทบทวนเมื่อ:** มีลูกค้าต้องการวิเคราะห์วิดีโอต่อเนื่องฝั่งเซิร์ฟเวอร์ → เพิ่ม Python service เฉพาะงานนั้น (ไม่ rewrite)

## ADR-003: Supabase เป็นแกนกลาง (DB + Storage + Auth + คิว pgmq)
- **เหตุผล:** ผู้พัฒนาใช้อยู่แล้ว; เป็น Postgres แท้จึงมีประตูออก (dump ย้าย/self-host ได้); ลดจำนวนระบบที่ต้องดูแลเหลือน้อยที่สุด; ปริมาณ event ระดับสิบไซต์ Postgres ตัวเดียวเอาอยู่
- **ทบทวนเมื่อ:** บิลเกินหลักหมื่น/เดือน หรือ 30-50+ ไซต์ → พิจารณา self-host

## ADR-004: ไม่มี face recognition ใน v1
- **เหตุผล:** ข้อมูลชีวภาพภายใต้ PDPA ต้องขอ consent ยุ่งยากและเสี่ยงกฎหมาย; LPR/นับคน/ตรวจโซน ให้มูลค่าเกือบเท่ากันโดยติดแค่ป้ายแจ้ง CCTV ปกติ
- **ทบทวนเมื่อ:** มีลูกค้าต้องการจริงจัง + ปรึกษาทนาย PDPA แล้ว

## ADR-005: Fail-open — VLM ล่มต้องไม่ทำให้แจ้งเตือนเงียบ
- **ตัดสินใจ:** VLM timeout 20 วินาที → ส่ง alert ดิบ (ไม่มีคำบรรยาย) ทันที
- **เหตุผล:** พลาดเหตุจริงเสียหายกว่า alert ไม่สวย; ความเชื่อใจของลูกค้าคือ asset หลัก

## ADR-006: LINE เป็นช่องทางแจ้งเตือนหลัก
- **เหตุผล:** นิติ/รปภ.ไทยอยู่ใน LINE ไม่เปิดเว็บ; รองรับรูป + ปุ่มโต้ตอบ
- **ข้อระวัง:** LINE คิดเงินตาม push message → การกรอง alert หลอกด้วย VLM คือการประหยัดต้นทุนโดยตรง
- **ทบทวนเมื่อ:** ค่า LINE ต่อไซต์เกิน ~300 บาท/เดือน → พิจารณา digest/แอปแจ้งเตือนเอง

## ADR-007: เชื่อมไซต์ผ่าน Tailscale เท่านั้น ห้าม port forward
- **เหตุผล:** NVR เปิดพอร์ตสาธารณะโดนแฮ็กเร็วมาก และความเสียหายจะย้อนทำลายแบรนด์เรา; Tailscale outbound-only ทะลุ NAT เน็ตหมู่บ้านได้ ฟรีถึง 100 เครื่อง

## ADR-008: เก็บ raw payload ทุก event + feedback "แจ้งเท็จ" ตั้งแต่วันแรก
- **เหตุผล:** สองอย่างนี้คือสมบัติที่ลอกไม่ได้ — ใช้ debug, จูน prompt VLM, เทรนโมเดลอนาคต; เพิ่มทีหลังจะเสียข้อมูลช่วงแรกไปตลอดกาล

## ADR-009: กลยุทธ์ราคา "ถูกตอนเข้า แพงตอนโต"
- **ตัดสินใจ:** แพ็กเกจต่อโครงการ (ไม่ใช่ต่อกล้อง) เริ่ม ~1,990-5,990 บาท/เดือน + ค่าติดตั้ง; add-on และ segment พรีเมียม (โรงงาน/รปภ./multi-site เริ่ม 9,900+) เก็บมูลค่าภายหลัง; lock ราคา 12 เดือนในสัญญา
- **เหตุผล:** งบนิติจำกัด อนุมัติหลักพันง่าย; มูลค่าเก็บตอนลูกค้าสัมผัสของจริงแล้ว ไม่ใช่ตอนขอความเชื่อใจครั้งแรก
